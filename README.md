# AI-Powered-Desk-Buddy
Desk Buddy: an ESP32-S3 AI desk robot with voice chat (Groq Whisper speech-to-text, LLM and Orpheus text-to-speech), animated OLED face, internet radio, camera vision and live MJPEG streaming. Includes Arduino firmware and a native Android app (Kotlin, Jetpack Compose) for Bluetooth LE control.
